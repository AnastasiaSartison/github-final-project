# Simple Interest Calculator

This project contains a simple Bash script that calculates simple interest.

## Project Description

The Simple Interest Calculator takes input from the user for:

- Principal amount
- Rate of interest
- Time period

It then calculates simple interest using the formula:

Simple Interest = (Principal × Rate × Time) / 100
